# AI-RVC v1.7.0 发布说明

AI-RVC 1.7.0 增加同曲调参复用、批量翻唱和双主题工作台，提供 Windows / Linux 的 CPU 与 NVIDIA CUDA 便携包，以及 Linux CPU 和 CUDA 容器镜像。

### 主要更新

- **全新双主题工作室界面**：新增日间 / 夜间模式即时切换（支持跟随系统与本地记忆），重构全套页面卡片排版与响应式布局，并将「歌曲翻唱」设为默认首屏；多轨播放器同步支持双主题与中英双语。
- **同曲调参复用与批量翻唱**：同页面微调音调、更换声线或重混音量时自动复用已完成阶段；新增批量队列翻唱，支持逐首试听分轨及整批成品 ZIP 打包下载。
- **整曲与纯人声批次**：在工作台的「批量翻唱」内上传多个文件。损坏文件单独报告，其他条目可继续处理。Colab 笔记本也提供批量上传和 ZIP 导出。
- **音频质量与精度优化**：同步 TelkNet 同源音频更新，改善转音过渡与长歌曲拼接；修复 GTX 16 系列显卡在 SM 7.5 下的半精度选择问题，保留模型原生精度与精确 FAISS 检索。
- **打包与稳定性修复**：内置 FFmpeg 运行时，修复 Numba 离线缓存路径定位、双索引角色包识别、官方 UVR5 模块路径缓存及跨语言切换刷新问题，精简前端开发依赖。
- **文案与翻译全面精校**：全面清理界面、文档与英文控制台词典，修正角色名及技术术语翻译。

> **安装提示**：请下载对应平台的全部压缩分卷及 `SHA256SUMS` 校验文件，放于同一目录解压至新文件夹后启动。

## English

AI-RVC 1.7.0 adds stage reuse, batch covers and a dual-theme workspace. It ships Windows/Linux CPU and NVIDIA CUDA portable builds and Linux CPU and CUDA container images.

### Highlights

- **Studio UI with Light & Dark Themes**: Instant Light/Dark mode toggle (following system preference with local persistence), redesigned card-based workspace layout with Song Cover as the default tab, and synchronized dual-theme multitrack player.
- **Same-Song Stage Reuse & Batch Covers**: Automatically reuses completed separation or conversion stages when tweaking pitch, voice, or mix parameters in the same session; adds sequential batch processing with per-track preview and ZIP export.
- **Song and Vocals-Only Batches**: Upload multiple files from Batch Covers in the workspace. Invalid files keep their individual errors while the remaining items continue. The Colab notebook also supports batch uploads and ZIP export.
- **Audio & Precision Improvements**: Integrates shared TelkNet audio refinements for smoother pitch transitions and long-song joins; fixes GTX 16-series precision selection while preserving native model precision and exact FAISS retrieval.
- **Packaging & Reliability Fixes**: Bundles FFmpeg runtime, resolves relocatable Numba caching, paired `trained_`/`added_` character archives, frozen official UVR5 module cache invalidation, and cross-locale UI reload stability.
- **Localization Polish**: Refined bilingual UI copy, documentation, and English console localization across character names and audio terminology.

> **Installation**: Download all archive volumes and the matching `SHA256SUMS` file into one folder, verify checksums, and extract into a fresh directory.
