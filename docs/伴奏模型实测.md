# 伴奏模型实测与默认值

测量日期：2026-09-05、2026-09-06。当前默认为 `hybrid:leap_xe90_vocals+leap62_instrumental`：Leap XE 90 提取人声，标准 Leap Instrumental 62 提取纯伴奏。PolarFormer 已从运行路线移除，以下仅保留历史对比数据。

## 当前版本复测：2026-09-06

audio-separator 升至 0.47.0 后，使用与旧记录相同的 30 秒输入、参考轨和模型权重，在同一 RTX 4070 Ti SUPER 上串行重新运行两模型。Leap 使用当前项目加载器，FP32、关闭 autocast / 原生 FP16 / compile，`num_overlap=2`；该次 PolarFormer 测量使用移除前的 ONNX 封装。

本次 Leap 高 **0.8280 dB**。当前复测 2 次推理全部成功，4 路输出均为 44.1 kHz 双声道、1,323,000 帧，数值有限。两次输入 SHA-256 一致：`0d4b0edeb9dadfc79660432ef4190e8400d890bb97468e3db4c33e94fd4bff56`；参考轨 SHA-256：`c319960ccf17ef110536e74358860494768afca30edd11dd1f19a5c945d0388f`。可读取[完整精度指标与输出哈希](伴奏模型实测_2026-09-06.json)。

0.47.0 修正重叠及尾部拼接，当前 Leap 分数较 0.44.1 的 19.3401 dB 略低，不能把升级描述为必然提升音质。此次未重复测量旧 60 秒原曲的速度，下节保留的 9.69 / 287.47 秒只属于旧版记录。单次耗时会受硬件负载影响，不构成性能保证。

以下保留 audio-separator 0.44.1 的历史测量，不能将其耗时、质量分数当作新版结果。

## 历史记录：0.44.1，同一受控样本

| 模型 | SI-SDR ↑ | 固定增益 SDR ↑ | 推理耗时 |
|---|---:|---:|---:|
| Leap Instrumental | 19.3401 dB | 19.3730 dB | 4.97 秒 |
| PolarFormer public ONNX 62 | 18.4565 dB | 18.5177 dB | 162.41 秒 |

| 同一样本的连续分段 | Leap SI-SDR | PolarFormer SI-SDR |
|---|---:|---:|
| 0–10 秒 | 22.1552 dB | 21.3288 dB |
| 10–20 秒 | 18.0992 dB | 17.1488 dB |
| 20–30 秒 | 16.6410 dB | 15.7609 dB |

以《群青钢琴》的 60–90 秒为参考，将既有《Far far away》分离人声的 45–75 秒调整为相同 RMS 后叠加，共同缩放到峰值 0.8。参考轨在混合前保存。输入统一为 44.1 kHz 双声道 PCM16；两模型输入哈希一致，不使用任一模型输出作为另一模型的参考。

SI-SDR 对完整 30 秒计算，每声道去直流、双声道共享增益，不按候选结果另行移时或挑选区间。计算方法通过增益不变性、完美重建和独立相关系数公式自检，依据 [SI-SDR 论文](https://arxiv.org/abs/1811.02508)。附带 SDR 为固定增益能量比，非 BSS Eval 滤波拟合分数。

这是一段跨歌曲人工混音；分离人声可能含串音，三个分段也不是三首独立歌曲。结果只说明本次恢复指定钢琴参考时 Leap 领先 0.8836 dB，不证明所有歌曲、配器和人声上都更好。

## 历史记录：0.44.1，真实歌曲片段

《Far far away》45–105 秒，两模型均输出 60 秒有效双声道伴奏：Leap 9.69 秒，PolarFormer 287.47 秒。没有通过同源精确对齐核验的原版伴奏，故不报告原曲 SDR 或音质总分。两模型接近满幅采样比例均为 0；这不代表没有人声残留或乐器损伤。

共 2 个样本、2 个模型、4 次真实推理，4 次成功；8 路输出通过非空、有限数值、采样率、声道数及长度检查。尚未进行真人盲听验收。
