# 平台适配与验收记录

本文记录 AI-RVC 在各操作系统、容器、云端平台与浏览器环境下的支持情况及核心验收结果。

## 平台支持总览

| 平台 / 运行入口 | 支持状态 | 说明与验收范围 |
|---|---|---|
| **Windows 10/11 (x64)** | 完整支持 | 提供 CPU / NVIDIA CUDA 便携包与本地安装；通过完整回归、冻结音频/缓存校验、长曲整曲与纯人声、同曲复用、批量翻唱及桌面/移动视口 Chrome 验收 |
| **Linux (Ubuntu / Debian x64)** | 完整支持 | 提供 CPU / NVIDIA CUDA 便携包与本地安装；支持 CUDA 与 CPU 后端，ROCm / XPU 需本地预装对应 PyTorch 运行栈 |
| **WSL2 (Ubuntu / Debian)** | 完整支持 | 支持源码安装及 Docker CPU / CUDA 运行，WebUI 默认地址 `http://127.0.0.1:7860` |
| **Docker (Linux x86-64)** | 完整支持 | 提供 `1.6.0-cpu` / `1.6.0-cuda` 官方镜像，完成非 root (UID 1000)、断网离线三路线、持久化、鉴权、反向代理与备份恢复验收 |
| **Google Colab** | 已提供 | `AI_RVC_Colab.ipynb` 自动搭建独立 Python 3.10 + CUDA 环境，支持笔记本内批量上传翻唱与 ZIP 下载 |
| **Hugging Face Spaces** | 已提供 | 默认 CPU 运行配置（`requirements_hf.txt` + `app.py`），可按需切换为 GPU Space |
| **macOS (Apple Silicon)** | 实验性 | 安装器与 CI 支持 PyTorch 2.13 + TorchAudio 2.11 (ARM `libsamplerate`)，MPS 全链翻唱持续完善中 |
| **DirectML** | 部分支持 | `audio-separator==0.47.0` 上游暂不支持 DirectML 运行 MDXC/RoFormer，默认六模型链请使用 CUDA 或 CPU |

## 核心功能验收摘要（1.6.0）

### 1. 长歌曲整曲与同曲复用（Windows CUDA / RTX 4070 Ti SUPER）

以 240.98 秒 48 kHz 双声道 MP3（国木田花丸 Zurakichi v2 声线、默认六模型链）实测：

| 操作场景 | 实测耗时 | 验证结果 |
|---|---:|---|
| 首次完整整曲翻唱 | 320 秒 | 七类 Float WAV 完整解码，成品 44.1 kHz 双声道，峰值 0.979 |
| 原主唱混入调整为 25% | 6 秒 | 复用全部 4 个阶段，六条组成音轨 SHA-256 逐字节一致，最终混音实时更新 |
| 保持 25% 混入并升 2 半音 | 51 秒 | 复用五条分离音轨，转换人声与成品更新，有声帧音高中位变化 `+1.997` 半音 |
| 保持上述参数更换角色（星空凛） | 44 秒 | 复用五条分离音轨，转换人声与成品正常切换 |

### 2. 批量队列、错误隔离与多终端浏览器

- **桌面 Chrome**：整曲与纯人声批量队列依次提交有效曲目、损坏 WAV、改名副本及同名不同内容片段；损坏项独立展示解码错误，有效项全部完成并打包为可校验的 ZIP，单首与批次间播放器切换及中英文刷新恢复正常。
- **移动端浏览器**：Android 14 模拟器 Chrome 113 与 WebKit iPhone 15 视口（393 px）均完成上传、纯人声批量处理、切歌试听、播放/暂停与 ZIP 下载，页面零横向溢出、零控制台异常。
- **便携包与冻结运行时**：Windows / Linux CPU & GPU 四种便携包均在独立中文目录完成冷/热 Numba 缓存验证（缓存命中 0 → 1）、Float64/Float32 混响对照、DOUBLE WAV 混音、GPU 包 NVRTC 实际编译，以及原包 Chrome 中英文切换与刷新验收。
- **Docker 与笔记本工作进程**：Debian / WSL2 Docker CUDA 与 CPU 镜像完成非 root 离线默认、官方 UVR5 与纯人声三路线，笔记本工作进程完成同曲复用与批量 ZIP 导出。

### 3. 安全与依赖兼容记录

- **Python 3.10 固定运行时**：项目本地安装、便携包、Colab 与 Docker 统一使用 Python 3.10 与 Gradio 5.49.1，在 Windows 环境下路径校验正常拦截越界访问（CVE-2026-28414 仅影响 Windows + Python 3.13+ 组合）。
- **依赖锁定**：统一通过 `pre-requirements.txt`（pip 24.0 / setuptools 69.5.1）解析 `fairseq==0.12.2`、`audio-separator==0.47.0`、`gradio==5.49.1` 与匹配后端的 PyTorch 三件套，确保 `pip check` 零冲突。
